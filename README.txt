HOW TO USE:
1. Put your own images inside assets/ folder.
2. Rename your main profile/banner image to: profile.jpg
3. Put project images inside assets/projects/ and rename:
   wallet.jpg, sunglasses.jpg, peanut.jpg, toy.jpg
4. Edit index.html text with your final information.
5. Upload all files to GitHub repository.
6. Go to Settings > Pages > Deploy from branch > main > /root.
