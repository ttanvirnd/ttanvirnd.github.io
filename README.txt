Tanvir Portfolio V2

Upload to GitHub Pages:
1. Extract this zip.
2. Upload all files and folders to your GitHub repo.
3. Replace assets/profile.jpg with your portrait.
4. Replace category cover images in assets/category-covers/.
5. Add more portfolio images inside assets/projects/category-name/.
6. If you add more than 6 images, open the matching HTML page and copy another gallery-item line with the new image name.
