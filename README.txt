HOW TO USE:

1. Upload your own main hero image:
   assets/profile.jpg

2. Upload your project images:
   assets/projects/wallet.jpg
   assets/projects/sunglasses.jpg
   assets/projects/peanut.jpg
   assets/projects/toy.jpg

3. Keep the file names same OR edit image paths inside index.html.

4. Upload all files to GitHub:
   index.html
   style.css
   script.js
   assets folder

5. Go to GitHub Settings > Pages > Deploy from branch > main > /root.

NOTE:
Best hero image style:
- portrait photo
- clean background
- black and white works best
- full body or upper body portrait
